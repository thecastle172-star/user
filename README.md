# القلعة عقارات الدورة

واجهة عرض العقارات العربية المبنية بـ React وTypeScript وVite.

## التشغيل والتحقق

```bash
npm install
npm run dev
npm run build
npm run lint
```

يقرأ التطبيق العقارات والبنرات ورقم واتساب من Convex، ثم يحفظ نسخة من المتغيرات في `localStorage` لمدة ست ساعات. عند وجود نسخة حديثة لا تُنفذ قراءة جديدة من قاعدة البيانات، وعند انقطاع الشبكة تُعرض آخر نسخة محفوظة أو البيانات الاحتياطية المضمنة.
